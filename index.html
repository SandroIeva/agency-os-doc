In development — Phase 1

Agency OS — the workspace for creative teams

A native desktop application that combines project management, brand intelligence, team communication, and multi-model AI in one unified experience. Built with Tauri 2, React, and Supabase. macOS first.

Concept

One app instead of twelve

Creative agencies run on Slack, Notion, Figma, Google Drive, Asana, invoicing tools, and scattered spreadsheets. Agency OS replaces this fragmented workflow with a single native application.

Not a PM tool with AI bolted on

Agency OS is a brand intelligence platform with operations and real-time communication attached. The AI knows your brand voice, personas, and guidelines — every output is on-brand by default.

Native desktop, not another browser tab

Tauri 2 delivers a 3–8 MB binary that launches in under 0.5 seconds and uses 30–50 MB RAM. No Electron bloat, no web app lag. System notifications, file system access, offline resilience.

Obsidian meets aWork

Knowledge management with the depth of Obsidian — Markdown docs, linked references, brand knowledge base. Task delegation and team coordination with the structure of aWork — kanban, calendar, time tracking.

Multi-model AI via OpenRouter

Every team member chooses their preferred AI model — Claude, GPT, Gemini, Llama. One API, one billing, all models. Brand context is injected into every prompt regardless of which model responds.

AI integration

Multi-model AI with brand knowledge

The AI layer is not a chatbot bolted on. It's the intelligence backbone woven into every module.

Voice interface

Press the mic button to speak. Web Speech API transcribes in real-time. The AI responds through a 3D animated sphere (Three.js GLSL shaders) with speech synthesis. Full conversational flow without typing.

Per-user model selection

Each team member picks their preferred model in settings. All models receive the same brand context. Claude for nuanced writing, GPT-4o for speed, Gemini for multimodal. OpenRouter handles routing and billing.

Brand context injection

Before any prompt reaches any model, a system prompt is built from your brand knowledge: tone of voice, personas, positioning, guidelines. Stored in Supabase, editable by the team, injected automatically.

AI agents (Task Force)

Autonomous agents with defined skills — competitor analysis, content drafting, research synthesis. Assign a task to an agent, get a notification when it's done. Each agent inherits the brand context.

LLM context

Context for AI assistants

If you're an LLM helping build Agency OS, here's what you need to know.

Project identity

Project: Agency OS (also referred to as "i7 OS" in UI branding) Author: Sandro Ieva — sandroieva.com — mail@sandroieva.com Type: Native desktop application for creative agencies and micro-studios Stage: Prototype / MVP in active development Repository: github.com/SandroIeva/agency-os-prototype Deployment: Vercel (prototype), Tauri desktop (production target)

Tech stack

Desktop shell: Tauri 2 (Rust) — macOS first, then Windows, then iOS/Android Frontend: React 19 + Vite + Tailwind CSS Backend: Supabase (PostgreSQL + Auth + Realtime + Storage) — EU Frankfurt AI: OpenRouter API (multi-model: Claude, GPT, Gemini, Llama) Animations: Framer Motion (UI) + Three.js GLSL shaders (AI sphere) Voice: Web Speech API (input) + speechSynthesis (output) Sound: Web Audio API (synthesized, no external files) Collaboration: Tiptap + Yjs (CRDT) for real-time doc editing Communication: Supabase Realtime (chat) + LiveKit (voice/video) Styling: Tailwind CSS + Radix UI + Geist font State: Zustand + React Query

Architecture principles

1. SINGLE USER FIRST — build every feature for one user before adding team support 2. BRAND CONTEXT INJECTION — every AI call includes brand voice, personas, guidelines 3. MODEL AGNOSTIC — OpenRouter handles routing; user selects preferred model 4. NATIVE FIRST — use Tauri APIs for notifications, file system, system tray 5. OFFLINE RESILIENT — React Query cache + optimistic updates 6. RESPONSIVE FROM DAY 1 — CSS breakpoints for future mobile companion 7. SUPABASE RLS — user_id on every table from the start, enforce in Phase 3

Design language

Theme: Dark (#0B0B0F background, #111117 surfaces) Font: Geist (sans-serif) — all UI text Accent: Purple-pink gradient (sphere), white (active states) Corners: Large radius (16-28px on cards, 50% on icons) Animations: Framer Motion springs, soft easing [0.22, 0.68, 0.35, 1.0] Sound: Sine wave tones, ascending arpeggios for positive actions Sphere: Three.js with GLSL fragment shader (FBM noise, rose-purple-blue palette) Menu: Circular segmented ring, scroll-to-navigate, orbital card sub-items Icons: Custom SVG icons with rounded stroke style

Module structure

TASKS → Time Tracking, Delegate Tasks CHAT → Team, Clients, Channels, AI Chat, Calls PLAN → Calendar, Governance, Kanban (project level) FILES → Brand Core, Brand Assets, Images, Competitor, Personas, Raw, Links CREATE → Mini Apps (Brainstorm, Campaigns, Visuals, Templates) TASK FORCE → AI Agents, Skillz PROJECTS → Container linking tasks, chat, files, docs per project
